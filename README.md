# Frontend-часть сервиса по изучению иностранных слов WorDrop

Репозиторий содержит исходный код клиентской части веб-приложения **WorDrop**, предназначенного для изучения иностранных слов и отслеживания статистики обучения. Фронтенд взаимодействует с серверной частью через REST API и сохраняет JWT-токен в `localStorage` браузера для поддержания сессии пользователя.

---

## Связанные репозитории
* **Backend-часть сервиса по изучению иностранных слов WorDrop:** [WorDrop-Backend](https://github.com/kal1van1ch/WorDrop-Backend)

---

## Технологический стек

| Компонент / Библиотека | Используемая технология | Назначение в проекте |
| - | - | - |
| Библиотека интерфейса | React | Построение компонентного UI и управление состоянием приложения. |
| Инструмент сборки | Vite | Быстрая сборка фронтенда и запуск локального сервера разработчика. |
| Маршрутизация | React Router DOM | Навигация между экранами (вход, регистрация, личный кабинет, тренировки) без перезагрузки страницы (SPA). |
| Взаимодействие с API | Axios | Отправка асинхронных HTTP-запросов на Spring Boot бэкенд и автоматическое прикрепление JWT-токена в заголовки. |
| Стилизация | CSS-модули | Кастомизация интерфейса, стилизация карточек слов, форм и адаптивный дизайн. |

## Быстрый запуск

### 1. Требования перед запуском
Убедитесь, что на вашем компьютере установлены:
* **Node.js** (рекомендуемая версия LTS)
* **npm** (поставляется вместе с Node.js)

### 2. Установка зависимостей
Создайте директорию и склонируйте в неё репозиторий. Перейдите в данную директорию и выполните команду для загрузки всех необходимых пакетов:

```bash
npm install
```

### 3. Запуск 
Перейдите в директорию с проектом выполните следующую команду:

```bash
npm run dev
```

В результате в терминале отобразится локальный адрес, по которому можно открыть проект в браузере:
